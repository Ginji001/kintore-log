# 筋トレ記録

ジムのトレーニングを記録して、月ごとに振り返る無料のWebアプリです。

https://ginji001.github.io/kintore-log/

- ログイン不要。記録は使っている端末のブラウザの中（IndexedDB）だけに保存し、サーバーには送信しません
- 曜日ごとのメニューを作ると、その日の種目と前回の重量が自動で入ります。全セットが目標回数の上限に届いた種目は、次回1段階重くします（アシスト種目は1段階軽く）
- テンプレート（全身・上半身／下半身・押す引く脚）から始めるか、一から作れます
- マシンの重量段階はジムに合わせて変えられ、種目ごとにも設定できます
- カレンダー、人体図つきの部位別セット数、種目ごとの実施日を表示します
- ホーム画面に追加するとアプリとして使え、オフラインでも開けます
- 機種変更の前は「設定」→「バックアップ」で書き出してください

重量や回数の提案は記録をもとにした目安で、医療やトレーニング指導の代わりではありません。
